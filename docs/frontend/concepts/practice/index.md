# 实战项目总览

从实践中学习，在项目中成长。本栏目通过三个递进式的实战项目，将理论知识转化为实际能力。

## 项目路线

```
入门项目 → TodoList 应用
  ├── 练习基础 CRUD 操作
  ├── 掌握组件化思维
  └── 理解状态管理

进阶项目 → 后台管理系统
  ├── 复杂路由与权限控制
  ├── 数据表格与表单处理
  └── 对接真实 API

综合项目 → 个人博客搭建
  ├── VitePress 静态站点
  ├── Markdown 内容管理
  └── 自动化部署
```

## 项目对比

| 项目 | 难度 | 技术栈 | 预计时间 | 核心收获 |
|------|------|--------|---------|---------|
| TodoList | ⭐⭐ | Vue3/React | 1-2 天 | 基础 CRUD、组件化 |
| 后台管理系统 | ⭐⭐⭐⭐ | Vue3 + TS | 2-4 周 | 工程化、权限、API |
| 个人博客 | ⭐⭐⭐ | VitePress | 1-2 周 | SSG、部署、内容 |

## 学习建议

```
1. 先理解需求，再动手编码
2. 先实现功能，再优化代码
3. 先跑通流程，再完善细节
4. 善用 Git，每完成一个功能就提交
5. 遇到问题先思考，再搜索，最后提问
6. 写代码时考虑可维护性和可扩展性
```
