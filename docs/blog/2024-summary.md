# 我的 2024 年总结

2024 年是充满挑战和成长的一年。回顾这一年，有收获也有遗憾，但每一步都值得记录。

## 📚 技术成长

### 深入学习了以下技术

- **Vue3 生态** - 深入理解组合式 API，实践了多个项目
- **TypeScript** - 在项目中全面采用 TypeScript，提升了代码质量
- **Vite** - 从 Webpack 迁移到 Vite，开发体验大幅提升
- **Node.js** - 学习了后端开发基础，搭建了个人 API 服务

### 开源贡献

今年参与了几个开源项目：

1. 为 VitePress 提交了文档修正
2. 给 VueUse 贡献了新的 Composable
3. 维护了自己的工具库，收获了 100+ Star
