# 前端知识图谱

一张完整的前端学习路线图，帮助你系统化地规划学习路径，从入门到精通。

## 学习路线

```
阶段一：基础入门（1-3 个月）
├── HTML 语义化
├── CSS 布局与动画
└── JavaScript 基础

阶段二：框架实战（3-6 个月）
├── Vue2 / Vue3
├── React
└── 状态管理 + 路由

阶段三：进阶提升（6-12 个月）
├── TypeScript
├── 性能优化
├── 数据可视化
└── 工程化

阶段四：高级精通（12 个月+）
├── 浏览器原理
├── 设计模式
├── 前端安全
├── 微前端
└── 架构设计
```

## 知识体系

### 基础层

| 知识点 | 重要度 | 学习时间 | 掌握标准 |
|--------|--------|---------|---------|
| HTML 语义化 | ⭐⭐⭐ | 1 周 | 能正确使用语义化标签 |
| CSS 布局 | ⭐⭐⭐⭐⭐ | 2 周 | 熟练 Flexbox + Grid |
| CSS 动画 | ⭐⭐⭐ | 1 周 | 能实现常见动画效果 |
| JS 基础语法 | ⭐⭐⭐⭐⭐ | 3 周 | 熟练 ES6+ 语法 |
| DOM 操作 | ⭐⭐⭐⭐ | 1 周 | 能操作页面元素 |
| 异步编程 | ⭐⭐⭐⭐⭐ | 2 周 | 理解 Promise/async |
| 事件机制 | ⭐⭐⭐⭐ | 1 周 | 理解冒泡/委托 |

### 框架层

| 知识点 | 重要度 | 学习时间 | 掌握标准 |
|--------|--------|---------|---------|
| Vue 基础 | ⭐⭐⭐⭐⭐ | 3 周 | 能独立开发 Vue 项目 |
| Vue 组件化 | ⭐⭐⭐⭐⭐ | 2 周 | 能设计可复用组件 |

### 工程层

| 知识点 | 重要度 | 学习时间 | 掌握标准 |

## 技术栈推荐

### 初学者

```
HTML + CSS + JavaScript
    ↓
Vue3 + Vite + Pinia
    ↓
TypeScript + ESLint
```

### 进阶开发者

```
Vue3 / React + TypeScript
    ↓
Vite + Pinia / Zustand
    ↓
ECharts + Vitest
```

### 高级开发者

```
框架源码 + 架构设计
    ↓
微前端 + Monorepo
    ↓
性能优化 + 工程化
```
